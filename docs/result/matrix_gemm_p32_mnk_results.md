# Matrix GEMM P32：MNK 与 LLM workload 实测结果

合成矩阵基线日期：2026-09-10；三个 LLM workload 的 45 组实测日期：2026-09-11。  
执行方式：每组均由 Kconfig 选择 workload/profile/MNK preset，再执行 `make run`；LLM 数据为真实 layer-0 attention-projection trace 的 tile 回放。  
仿真环境：Verilator 5.008、g++ 9.4.0、Linux 6.17.0、Intel Core i9-13900KF（32 logical CPUs）；trace 导出为 PyTorch 2.14.0+cpu、Transformers 5.16.1。

## 指标定义

- `requests`：送入 PVU 的四 lane MAC 请求数，等于 `M × N × ceil(K / 4)`。
- `valid_mac_terms`：有效 MAC 项数，等于 `M × N × K`。
- `request_per_cycle`、`mac_per_cycle`：由本次仿真的请求数、有效 MAC 项数和周期数计算。
- `lane_utilization`：有效 MAC 项数与所有请求 lane 容量之比。
- `exact_mismatches`：与 SoftPosit 结果不完全一致的 C 元素个数；`0` 表示全部精确一致。

## 合成矩阵基线结论

- 15 组测试均为 `exact_mismatches=0`，与 SoftPosit 参考结果精确一致。
- K 为 4 的倍数时 lane 利用率为 100%；K=63、65 和小 K 尾数用例的吞吐下降来自四 lane 最后一个请求未完全填满。
- 大矩阵下启动/收尾的固定 6 周期影响被摊薄，`CUBE_128` 达到 `3.999954 MAC/cycle`。

## 三个 LLM workload 的 trace 约定

为使所有内置 MNK preset 都可运行，三组结果均回放 layer 0 的单个 attention projection。每个条目是一个真实 trace 的 `M×K · K×N` tile：取前 M token、均匀选择 N 个输出通道和前 K 个输入通道。

| Profile | 模块 | 输入形状 | 权重形状 | 本次 trace 目录 |
| --- | --- | --- | --- | --- |
| Qwen3-0.6B | `self_attn.q_proj` | 128×1024 | 2048×1024 | `/tmp/qwen3-0.6b-p32-trace-mnk128-qproj` |
| Gemma 3 1B | `self_attn.q_proj` | 128×1152 | 1024×1152 | `/tmp/gemma-3-1b-p32-trace` |
| Phi-4-mini-instruct | `self_attn.qkv_proj` | 128×3072 | 5120×3072 | `/tmp/phi-4-mini-p32-trace` |

Qwen 原默认目录中已有一个 16-token、6 模块的历史 trace；它在 `M >= 32` 时会因 `down_proj` 的 token 维度不足而拒绝运行。为保留该目录且保证三模型 45 组结果可比，本表通过 Kconfig 将 Qwen trace 目录改为上表的新目录，由 `make run` 自动离线生成 128-token 单模块 trace。原 trace 未被改写。

LLM 表中的 `exact mismatches / status` 为 Hardware-vs-SoftPosit 一致性门；`ULP >=5` 与相对误差为 Ordered-FP32 的 tile 级观察值。每组只运行一次，不能解释为端到端 token/s 或系统 TOPS。

## LLM 结果摘要与写作边界

- 三模型共完成 45 组有效 tile：Qwen3-0.6B 为 6 PASS、9 FAIL；Gemma 3 1B 为 7 PASS、8 FAIL；Phi-4-mini-instruct 为 6 PASS、9 FAIL。`FAIL` 表示 Hardware-vs-SoftPosit exact mismatch 非零，不能写为硬件一致性通过。
- 吞吐主要由 MNK shape 决定，三模型的同形状调度结果一致。`CUBE_128` 达到 0.999989 request/cycle 和 3.999954 MAC/cycle；`K=65` 的最后一组未满 K tile 使 MAC/cycle 降至 3.822212。
- 上表的 Ordered-FP32 误差为 tile 级数值观察。所有 preset 的 K 均小于相应真实投影的完整输入维度，因此不能将其解释为完整 pre-bias 线性层输出误差。
- 结果均为单次 Verilator 仿真，不能报告均值、方差、置信区间、实际时钟频率、端到端 token/s 或系统 TOPS。若用于论文主结果，应补充重复运行策略与硬件综合或上板测量。
