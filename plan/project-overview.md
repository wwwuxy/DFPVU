# Project Overview

## Basic Information

- Paper type: IEEE IPDPS conference paper
- Field: computer architecture and vector arithmetic accelerators
- Working title: DFPVU: A Dual-Format Floating-Point Vector Processing Unit with RISC-V Vector Extension for Posit and IEEE 754 Floating-Point Arithmetic
- Output language: English primary version and Chinese companion version
- Output format: Markdown; no LaTeX template is present in the repository
- Current stage: S3/S4, experimental-results analysis and section drafting

## Research Objective

The paper argues that DFPVU extends the RISC-V vector programming model with high-throughput Posit and IEEE 754 arithmetic while maintaining low control overhead. The current comparison is limited to four-lane RTL cycle measurements; PPA evaluation will be added later.

## Current Deliverable

Produce an evidence-based comparison with four-lane Ara that emphasizes DFPVU's measured throughput, shape robustness, and dual-format functionality without claiming unsupported frequency, area, power, energy-efficiency, end-to-end LLM, or statistical-significance advantages.
